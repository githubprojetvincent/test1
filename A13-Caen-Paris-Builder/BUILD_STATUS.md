# A13 Caen → Paris — build installable

Une archive installable a été générée localement :
- 239 km de corridor procédural
- KN5 : a13_caen_paris.kn5
- route 2×2, marquages, accotements, glissières
- terrain, arbres, lampadaires, panneaux, échangeurs génériques, ponts
- points AC_START / AC_PIT / timing
- textures DDS incluses

Validation effectuée :
- archive ZIP : test unzip OK
- KN5 : lecture structurelle OK
- 34 meshes, maximum 60 000 vertices par mesh

Limitation : Assetto Corsa lui-même n'est pas installé dans l'environnement de génération, donc le chargement en jeu n'a pas pu être exécuté ici. La route et les coordonnées sont une reconstruction procédurale approximative basée sur des points géographiques publics ; ce n'est pas une reproduction OSM voie-par-voie.

Les assets Kunos propriétaires ne sont pas redistribués.

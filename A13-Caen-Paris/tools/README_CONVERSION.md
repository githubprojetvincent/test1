# Conversion finale KN5

1. Ouvrir models/a13_road.obj et models/a13_terrain.obj dans Blender.
2. Appliquer les transforms.
3. Exporter en FBX/OBJ compatible avec ksEditor.
4. Importer les meshes dans ksEditor.
5. Créer/exporter a13_road.kn5 et a13_terrain.kn5.
6. Placer les KN5 dans content/tracks/a13_caen_paris/.
7. Copier ce dossier dans content/tracks/ d’Assetto Corsa.
8. Générer la fast lane AI en jeu.

Le package n’embarque pas de textures ou modèles propriétaires Kunos.

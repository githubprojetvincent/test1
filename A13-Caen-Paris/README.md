# A13 Caen -> Paris — Assetto Corsa

Projet généré pour l’axe A13 Caen -> Paris.

Contenu : structure Assetto Corsa, géométrie procédurale route + terrain OBJ, configuration data/UI, source de centerline AI et guide de conversion KN5.

Important : la géométrie est une approximation procédurale du corridor A13, pas une reproduction topographique certifiée ni une copie de Google Street View.

La dernière étape indispensable pour une installation directe dans Assetto Corsa est l’export des OBJ en KN5 avec ksEditor, indisponible dans l’environnement de génération.
